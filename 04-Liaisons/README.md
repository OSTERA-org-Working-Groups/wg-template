# 04 Liaisons

This folder **MAY** contain public liaison statements exchanged between this working group and other organizations.

This repository is public. Liaison correspondence that is confidential to OSTERA members or to the other organization **MUST NOT** be stored here in GitHub and **MUST** be stored in the OSTERA Portal.
