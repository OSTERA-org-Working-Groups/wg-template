# 04 Liaisons

This folder is for liaison statements exchanged between this Working Group and other organizations.

## Detailed Documentation

The ["liaisons" documentation](https://github.com/OSTERA-org-Working-Groups/wg-tools/blob/v1/docs/liaisons.md) explains how to name incoming and outgoing liaison statements.

## Public Repository

This repository is public. Materials that are confidential to OSTERA members **MUST NOT** be stored here, or anywhere else on GitHub. They **MUST** instead be stored in the [OSTERA Portal](https://member.ostera.org/).

<!-- END STANDARD TEXT -->

Incoming liaison statements **MUST NOT** be stored in this repository or anywhere else on GitHub, unless the sending organization allows them to be made public. If they cannot be made public, they **MUST** only be stored in the [OSTERA Portal](https://member.ostera.org/).
