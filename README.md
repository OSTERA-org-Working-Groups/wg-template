## Participating

Participation in the development of work items in this repository is open to members of OSTERA. Information about membership is available at [ostera.org](https://ostera.org/).

However, anyone may comment on a draft during its public review, even if they are not a member of OSTERA. Each review page at https://pub.ostera.org/reviews/ explains how to comment.

## Intellectual Property

By submitting any contribution (an issue, a pull request, or a comment), you agree that your contribution is made under the [OSTERA IPR and Copyright Policy](https://ostera.org/policies/). Do not submit material that you do not have the right to contribute.

## How to Contribute

1. **Comments on a draft.** Open an issue in this [repository](https://github.com/OSTERA-org-Working-Groups/[WG_ID]/issues/new/choose) using the "Work Item Comment" template. Identify the document, its version, and the section you are commenting on.
2. **Propose text changes.** Fork the repository, create a branch, and open a pull request against the main branch. Keep each pull request to one logical change, and reference the related issue.
3. **Substantive technical changes.** Significant changes are discussed at working group meetings. The working group chair determines consensus in accordance with the OSTERA Working Methods.
