# 03 Work Items

This folder is for Working Group draft documents.

## Comments on Draft Documents

Participation is open to OSTERA members. However, anyone may comment on a draft during its Public Review. See [How to Participate](https://wg.ostera.org/participate/), and read the [Contributing Guidelines](https://github.com/OSTERA-org-Working-Groups/.github/blob/main/CONTRIBUTING.md) before you open an issue or a pull request.

To comment on a draft, open an issue in this repository using the [Work Item Comment template](https://github.com/OSTERA-org-Working-Groups/[WG_ID]/issues/new/choose). During a Public Review, comments can also be sent to [public-review@ostera.org](mailto:public-review@ostera.org).

## For Chairs and Editors

The ["work items" documentation](https://github.com/OSTERA-org-Working-Groups/wg-tools/blob/v1/docs/work-items.md) explains how drafts are named, released, and recorded, and the [`make` commands](https://github.com/OSTERA-org-Working-Groups/wg-tools/blob/v1/docs/work-items.md#commands) that record them.

The [Chair Guide](https://github.com/OSTERA-org-Working-Groups/wg-tools/blob/v1/docs/chair-guide/README.md) goes beyond the "work items" documentation, with step by step instructions.
