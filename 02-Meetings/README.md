# 02 Meetings

This folder **MAY** contain agendas (agenda.md), meeting reports (report.md), and other documents or materials that were presented during a specific meeting.

Each meeting **MUST** have its own subfolder, named with the date of the meeting, for example `2026-12-01`. Its agenda **MUST** be named `agenda.md` and its meeting report `report.md`, because the website links to those names. To list a meeting on the website, it **MUST** also be added to `06-Website/_data/meetings.yml`.

This repository is public. Reports or attachments that are confidential to OSTERA members **MUST NOT** be stored here in GitHub and **MUST** be stored in the OSTERA Portal.
